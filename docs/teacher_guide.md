# API хакатона ШЦТ — конспект для преподавателя

Состояние на 24 октября 2026 года.

## 1. Что это за проект

API хакатона — это сервер с готовыми данными. Дети подключают к нему свои Telegram-боты и Qt-приложения, и им не нужно писать серверную часть или искать данные. Сервер написан на FastAPI (Python 3.14), отдаёт JSON и работает только на чтение: все запросы — GET.

- **5 тематических блоков:** история, кулинария, кино, города, книги.
- **12 таблиц, 534 записи.** У большинства записей есть ссылка на картинку (`img_url`), поэтому данные хорошо подходят для ботов с фото.
- **85 эндпоинтов:** от простых («случайный фильм») до фильтров и поиска.
- **Базы данных нет.** Данные лежат в Python-словарях в папке `data/`. Сервер ничего не записывает, поэтому дети не могут случайно испортить данные запросами.

Как это работает: программа ребёнка вызывает `requests.get("http://<сервер>:8085/api/...")`, сервер берёт запись из словаря и возвращает JSON, а программа показывает его в чате или в окне.

## 2. Как запустить и проверить сервер

Сервер слушает порт **8085**. Всё в порядке, если в браузере ребёнка адрес `http://<IP-сервера>:8085/ping` показывает `"PONG!"`.

**Вариант А — Docker (для сервера в классе):**

1. `git clone https://github.com/Artem-Kornilov-pro/api_for_hakaton.git && cd api_for_hakaton`
2. `docker compose up --build -d` (или `make docker-up`)
3. Открыть `http://<IP>:8085/ping`, затем `http://<IP>:8085/docs`.

**Вариант Б — без Docker, на ноутбуке преподавателя (нужен Python 3.14):**

1. `make install` — создаст `.venv` и поставит зависимости.
2. `make run` — запустит сервер.
3. Узнать IP ноутбука в сети класса: macOS — `ipconfig getifaddr en0`, Windows — `ipconfig`. Этот адрес пишем на доске.

**`/docs` — главный инструмент на хакатоне.** Это автоматическая документация Swagger: там видны все 85 эндпоинтов, и каждый можно вызвать кнопкой «Try it out», чтобы увидеть ответ до того, как писать код.

**Что проверить заранее:**

- Сервер и компьютеры детей в одной сети. `localhost` у ребёнка — это его собственный компьютер, а не сервер.
- Порт 8085 не закрыт файрволом. macOS при первом запуске спросит разрешение — нажать «Разрешить».
- Из сети школы открывается Telegram (`api.telegram.org`): боты запускаются на компьютерах детей и ходят в Telegram сами.
- На компьютерах детей стоят Python и библиотеки из `examples/requirements.txt`. PyPI бывает медленным — ставить накануне, а не утром.
- Если сервер будет в Docker — образ `python:3.14-slim` скачан заранее (`docker pull python:3.14-slim`). Docker Hub бывает недоступен; запасной план — вариант Б.

Нагрузки бояться не нужно: тест на 60 одновременных пользователей прошёл без единой ошибки, среднее время ответа — 5 мс.

**Открытый вопрос:** на каком компьютере и по какому адресу будет работать сервер в день хакатона?

**Как работают фильтры.** Регистр букв не важен нигде. Но часть фильтров ищет точное совпадение, а часть — кусок слова:

- **Точное совпадение:** жанр фильма, тип блюда, династия, все фильтры городов и достопримечательностей. `/movies_by_genre/Драма` не найдёт «Экипаж»: у него жанр «Драма/Катастрофа».
- **Кусок слова:** всё в книгах, страна блюда, ресторан повара, имя режиссёра или актёра, континент, поиск. `/books_by_author/Пушкин` работает без имени и отчества.

Какие значения вообще бывают, показывают статистические эндпоинты: `/api/cooking/food_info` (страны и типы блюд), `/api/movies/movies_stats` (жанры), `/api/cities/cities_stats` (типы достопримечательностей), `/api/books/books_stats` (жанры), `/api/historic/stats` (династии).

## 4. Как дети обращаются к API

Детям достаточно библиотеки `requests` и метода `.json()`, который превращает ответ сервера в обычный словарь или список Python. Все примеры ниже запускались на настоящем сервере 24 октября; готовые файлы лежат в `examples/`.

**Первый запрос (5 минут):**

```python
import requests

API = "http://192.168.1.10:8085"  # адрес с доски

movie = requests.get(f"{API}/api/movies/random_movie").json()
print(movie["title"], movie["year"], movie["rating"])

# параметры после ? удобнее передавать словарём
found = requests.get(f"{API}/api/books/search_books", params={"query": "Пушкин"}).json()
for book_id, book in found["books"].items():
    print(book_id, book["title"])
```

- Кириллица в адресе работает: `requests` сам её закодирует.
- В «всех записях» ключи — строки: `movies["1"]`, а не `movies[1]`.
- У фильмов и книг название в поле `title`, у всего остального — в `name`.

**Telegram-бот** — `examples/bot_example.py`, библиотека pyTelegramBotAPI (`pip install pyTelegramBotAPI requests`). Для новичков она проще aiogram: нет `async`/`await`.

```python
@bot.message_handler(commands=["movie"])
def random_movie(message):
    movie = requests.get(f"{API}/api/movies/random_movie").json()
    text = f"{movie['title']} ({movie['year']})\nРейтинг: {movie['rating']}\n\n"
    text += movie["description"]
    try:
        bot.send_photo(message.chat.id, movie["img_url"], caption=text)
    except Exception:
        # Telegram не смог скачать картинку — отправим просто текст
        bot.send_message(message.chat.id, text)
```

`try/except` здесь обязателен: у части записей нет картинки (см. раздел 6), и без него бот падает на первой же такой записи. Все тексты в базе короче 1024 символов — в подпись к фото влезают.

**Qt-приложение** — `examples/qt_example.py`, PyQt6 (`pip install PyQt6 requests`). Самое важное в нём — заголовок при скачивании картинки:

```python
# Wikimedia не отдаёт картинки программам, которые не представились
HEADERS = {"User-Agent": "ShctHackathonApp/1.0 (school project)"}

data = requests.get(movie["img_url"], headers=HEADERS, timeout=10).content
pixmap = QPixmap()
pixmap.loadFromData(data)
```

Половина картинок лежит на Wikimedia, а она отвечает ошибкой 403 на запросы `requests` без заголовка `User-Agent`. Проверено: с `HEADERS` картинка грузится, без него — нет. В Telegram-боте картинку по ссылке скачивает сам Telegram, и заголовок там не задать. Отправку фото с настоящим токеном стоит проверить до хакатона, а `try/except` подстрахует.

## 5. Типичные ошибки и как быстро помочь

Первый шаг при любой проблеме — открыть тот же адрес в браузере ребёнка. Если в браузере виден JSON, сервер в порядке и ошибка в коде.

| Что видит ребёнок | Причина | Что сделать |
| --- | --- | --- |
| `ConnectionError`, `Connection refused` | Неверный адрес, `localhost` вместо IP сервера, сервер не запущен, компьютер в другой сети | Открыть `/ping` в браузере; сверить адрес с доской |
| `{"detail": "... не найден"}`, код 404 | Нет такого ID, или фильтр ничего не нашёл | Посмотреть в `/docs` или в `..._stats`, какие значения бывают |
| `{"detail": "Not Found"}` | Опечатка в самом пути (`/random_movies` вместо `/random_movie`) | Скопировать путь из `/docs` |
| Код 422 | Вместо числа передали текст (`/movies_by_year/два`) или забыли `?query=` у поиска | Проверить типы; передать `params={"query": ...}` |
| `KeyError: 1` | Взяли `data[1]`, а ID — строки | `data["1"]` или `data[str(n)]` |
| `KeyError: 'name'` | У фильмов и книг поле называется `title` | Распечатать `print(movie.keys())` |
| `TypeError: string indices must be integers` | `names_of_...` и `titles_of_...` отдают список строк, а не словари | Для полей взять `all_...` |
| Картинка не грузится в Qt | Wikimedia отвечает 403 без заголовка `User-Agent` | Добавить `headers=HEADERS` |
| Картинки перестали грузиться у всех сразу, код 429 | Весь класс выходит в интернет с одного IP, и Wikimedia ограничила частоту запросов | Не качать картинки в цикле; скачанную хранить в переменной |
| Бот падает на `send_photo` | У записи пустая или битая ссылка на картинку | Обернуть в `try/except` и отправить текст |
| `ValueError: Token must contain a colon` | Вставлен не токен или не целиком | Скопировать токен из @BotFather заново |
| Бот отвечает через раз, ошибка `409 Conflict` | Один токен запущен дважды: у двух ребят или в двух окнах | Один токен — одна запущенная программа |
| Вместо года смерти `None` | Человек жив | `if actor["death_year"] is None: ...` |
| Год основания отрицательный | Это год до н.э.: Рим — `-753` | `f"{-year} до н.э." if year < 0 else year` |

## 7. Шпаргалка: частые вопросы детей

- **Где посмотреть все адреса?** — `http://<сервер>:8085/docs`.
- **Можно добавить свои данные в API?** — Нет, API только читает. Свои данные (очки, избранное) храните в программе: в словаре, файле JSON или SQLite.
- **Почему случайный факт повторяется?** — Фактов 51, повтор неизбежен. Можно запоминать показанные ID и брать новые через `/facts`.
- **Как сделать викторину?** — Взять `/random_movie`, спросить год, сравнить ответ с `movie["year"]`. Варианты ответов — из `/titles_of_all_movies`.
- **Как сделать кнопки в боте?** — `telebot.types.InlineKeyboardMarkup` и обработчик `@bot.callback_query_handler`.
- **Бот будет работать после хакатона?** — Только пока запущены и программа ребёнка, и сервер API.
- **Сколько запросов можно делать?** — Сколько угодно, но не в бесконечном цикле без паузы.
