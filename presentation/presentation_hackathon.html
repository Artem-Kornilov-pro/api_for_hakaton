Адрес — это вопрос серверу

http://192.168.1.10
где сервер
:8085
порт
/api/movies
блок данных
/random_movie
что хотим

Меняешь конец адреса — сервер отвечает другими данными:

/api/historic/random_fact

случайный исторический факт

/api/cooking/dishes/by_type/Суп

все супы

/api/books/search_books?query=Пушкин

поиск книг и авторов

Ответ приходит в JSON

приходит от сервера
{ "title": "Иван Васильевич меняет профессию", "year": 1973, "director": "Леонид Гайдай", "genre": "Комедия", "rating": 8.8, "actors": ["Александр Демьяненко", ...], "img_url": "https://..." }
в Python это словарь
movie = response.json() movie["title"] # Иван Васильевич меняет профессию movie["actors"][0] # Александр Демьяненко

JSON — текст, похожий на словарь Python. .json() превращает его в настоящий словарь.

Первый запрос

import requests API = "http://192.168.1.10:8085" # адрес с доски movie = requests.get(f"{API}/api/movies/random_movie").json() print(movie["title"], movie["year"])

Трек 2: Qt-приложение

Случайный фильм
HEADERS = {"User-Agent": "ShctHackathonApp/1.0"} def show_movie(self): movie = requests.get(f"{API}/api/movies/random_movie").json() self.text.setText(movie["title"]) data = requests.get(movie["img_url"], headers=HEADERS).content pixmap = QPixmap() pixmap.loadFromData(data) self.picture.setPixmap(pixmap.scaledToWidth(300))

Не забудь headers

Без заголовка User-Agent половина картинок не загрузится: Wikimedia ответит ошибкой 403.

12

Частые ошибки

ConnectionError

Проверь адрес: не localhost, а адрес с доски. Открой /ping в браузере.

KeyError: 1

ID — строки: movies["1"]

KeyError: 'name'

У фильмов и книг поле называется title

404 Not Found

Такого нет. Посмотри в /docs, какие значения бывают.

Бот упал на send_photo

Не у всех записей есть картинка — оберни в try/except.

Нет картинки в Qt

Добавь headers=HEADERS в requests.get

Первым делом открой тот же адрес в браузере. Видишь JSON — сервер в порядке, ищи ошибку в коде.
